# Text Analyzer

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Analysis Tool](https://img.shields.io/badge/analysis-tool-green.svg)]()

A text analysis CLI with word count, readability, and detailed statistics.

## ✨ Features

- **Word Count** - Count words, characters, lines
- **Readability** - Flesch reading ease score
- **Sentiment** - Basic sentiment analysis
- **Top Words** - Most frequent words
- **Rich UI** - Beautiful colored output

## 📦 Installation

```bash
git clone https://github.com/Master-626/text-analyzer.git
cd text-analyzer
pip install .
```

## 🚀 Quick Start

```bash
# Analyze a text file
textan stats myfile.txt
```
